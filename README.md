# Titanic Survival Prediction (MERN)

A full-stack web application that predicts Titanic passenger survival using a Decision Tree Machine Learning model.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Python
- Decision Tree Classifier

## Features

- Add Passenger Details
- Store Data in MongoDB
- Predict Passenger Survival
- View Saved Passengers
- Delete Passenger Records

## Installation

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```
